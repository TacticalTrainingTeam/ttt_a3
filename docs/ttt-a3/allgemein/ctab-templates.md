Fügt dem cTab-Tablet vier Nachrichtenvorlagen hinzu, damit Meldungen schnell und einheitlich verschickt werden.

# Voraussetzungen

- [cTab Advanced](https://steamcommunity.com/sharedfiles/filedetails/?id=3438246217) - Erforderlich

# Benutzung

Die Vorlagen stehen beim Schreiben einer Nachricht im cTab zur Auswahl. Es gibt nichts einzurichten.

| Vorlage | Wofür | Anleitung |
| --- | --- | --- |
| NATO [MedEvac](/de/handbuch/nachschubkräfte/medevac) (9-Liner) | Medizinische Evakuierung. Wird im TTT nicht genutzt, muss für cTab aber vorhanden sein | - |
| TTT 5-Liner | Logistik, Personentransport und allgemeine Koordination | [5-Liner](/de/handbuch/nachschubkräfte/logistik#5-liner) |
| FDCB | Anforderung von Artillerie- oder Mörserfeuer | [FDCB](/de/handbuch/kampfunterstützungskräfte/artillerie/fdcb) |
| CAS 9-Liner | Anforderung von Luftnahunterstützung | [9-Line](/de/handbuch/luftstreitkräfte/close-air-support) |
