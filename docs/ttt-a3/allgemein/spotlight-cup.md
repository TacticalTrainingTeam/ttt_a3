Fügt dem Hauptmenü eine Kachel hinzu, die direkt auf den TTT-CUP-Server verbindet, und entfernt die Vanilla-Kacheln.

# Voraussetzungen

- [CUP Units](https://steamcommunity.com/workshop/filedetails/?id=497661914) - Erforderlich

# Benutzung

Im Hauptmenü auf die TTT-Kachel klicken. Verbunden wird mit `game.tacticalteam.de:2322`.
