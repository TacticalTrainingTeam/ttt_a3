Blendet per Tastendruck das gesamte Interface für Screenshots aus.

# Voraussetzungen

- [ACRE2](https://steamcommunity.com/sharedfiles/filedetails/?id=751965892) - Erforderlich

# Benutzung

Mit :block-kbd[Strg+F12]{platform="pc"} wird das Interface aus- und wieder eingeblendet. Das ist die ACE-Taste **UI ausblenden** (Kategorie **ACE3 Common**), dort lässt sie sich auch ändern.

Zusätzlich zu dem, was ACE ausblendet (ACE und DUI Squad Radar), blendet die TTT-Mod aus:

- das Vanilla-Interface
- die ACRE-Anzeigen
- [cTab](/de/ttt-a3/allgemein/ctab-templates): ein offenes Tablet wird geschlossen und beim Einblenden wieder geöffnet

Der Chat bleibt ausgeblendet, darum kümmert sich [Clear HUD](/de/ttt-a3/allgemein/clearhud).
