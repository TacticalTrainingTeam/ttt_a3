Fügt dem Hauptmenü eine Kachel hinzu, die direkt auf den TTT-RHS-Server verbindet, und entfernt die Vanilla-Kacheln.

# Voraussetzungen

- [RHS: USAF](https://steamcommunity.com/sharedfiles/filedetails/?id=843577117) - Erforderlich

# Benutzung

Im Hauptmenü auf die TTT-Kachel klicken. Verbunden wird mit `game.tacticalteam.de:2332`.
