# Clear HUD

Blendet den Chat im Multiplayer standardmäßig aus. Fügt einen Keybind hinzu um den Chat ein- und auszublenden. Basiert auf _Soldias Clearhud_.

Beim Umschalten wird ein Hinweis angezeigt, der den aktuellen Status sowie die verwendete Taste angibt.

Standard-Tastenkombination: ++shift+comma++ - kann über das Konfigurationsmenü geändert werden.
