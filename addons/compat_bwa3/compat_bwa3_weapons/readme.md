# Compat BWA3 - Weapons

Stellt die Nebelmittelwurfanlage der BWmod-Fahrzeuge als eigene Waffe bereit (`ttt_compat_bwa3_weapons_SmokeLauncher`), damit Richtschütze und Kommandant sie über das Smoke-Launcher-Addon abfeuern können. Benennt außerdem die Nebelgranaten in "Schnellnebelwurfkörper DM55" um.
