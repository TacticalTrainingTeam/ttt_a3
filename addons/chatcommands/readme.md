# Chat Commands

Stellt Chat Befehle zur Verfügung um im Notfall die Mission zu beenden oder einen neuen Zeus festzulegen

Ist [Zeus Enhanced (ZEN)](https://zen-mod.github.io/ZEN/) geladen, steht Curatoren zusätzlich eine Kontextmenü-Aktion zur Verfügung, um per Rechtsklick auf einen Spieler diesen zu Zeus zu befördern (siehe `chatcommands_zen`).
