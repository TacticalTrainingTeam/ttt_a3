# TTT Reparaturstation Fahrzeug

Fügt bestimmten Fahrzeugen die Möglichkeit hinzu ein Objekt, wie z.B. einen Cargokran, über eine ACE-Fremdinteraktion aufzubauen. Die eigentliche Auf-/Abbau-Logik teilt sich dieses Addon mit `medic_vehicle` über die interne Bibliothek `facility_construction`.
