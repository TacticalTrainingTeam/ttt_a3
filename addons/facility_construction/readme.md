# Facility Construction

Interne Bibliothek für Addons, die über eine ACE-Fremdinteraktion ein Objekt (z.B. Zelt, Werkstatt) in der Nähe eines Fahrzeugs auf- und wieder abbauen lassen. Wird aktuell von `medic_vehicle` und `repair_vehicle` genutzt, hat selbst aber keine eigenen Einstellungen oder Inhalte - jedes nutzende Addon übergibt seine eigene Konfiguration (Fahrzeugliste, Facility-Objekt, Texte, Animation, ...).
