# Compat Redd'n'Tank - MG3

Ermöglicht es die Lafette mit MG3s aus anderen Mods aufzubauen.

- `BWA3_MG3`
- `BWA3_MG3_bipod`
- `BWA3_MG3_MicroT2_pointer_bipod`

Behebt einige Fehler.

Macht MG3-Lafette stabiler.

Lafettieren dauert 5 Sekunden, Abbauen 10 Sekunden (`MG_MOUNT_TIME`, `MG_DISASSEMBLE_TIME` in `compat_rnt/script_component.hpp`). Früher waren die Zeiten als CBA-Einstellungen änderbar; die Einstellungen sind entfallen, weil die Standardwerte reichen.
