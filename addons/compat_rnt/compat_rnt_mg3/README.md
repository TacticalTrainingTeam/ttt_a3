# Compat Redd'n'Tank - MG3

Ermöglicht es die Lafette mit MG3s aus anderen Mods aufzubauen.

- `BWA3_MG3`
- `BWA3_MG3_bipod`
- `BWA3_MG3_MicroT2_pointer_bipod`

Behebt einige Fehler.

Macht MG3-Lafette stabiler.

Geladen werden kann der `Redd_Mg3_Belt_100` und die 150-Schuss-Kästen `150Rnd_762x51_Box` (auch Leuchtspur). Die MG3-Gurte der BWMod kommen aus `compat_rnt_mg3_bwa3`.

Lafettieren dauert 5 Sekunden, Abbauen 10 Sekunden (`MG_MOUNT_TIME`, `MG_DISASSEMBLE_TIME` in `compat_rnt/script_component.hpp`).
